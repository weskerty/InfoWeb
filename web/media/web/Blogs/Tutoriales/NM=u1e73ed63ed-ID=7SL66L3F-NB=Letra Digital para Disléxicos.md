# Fuentes digitales para dislexia

Fuentes que te ayudan a leer sin confusiones en pantallas.

## OpenDyslexic


![OpenDyslexic_specimen](web/adjuntos/7SL66L3F/1771296729430.svg)




Esta Fuente es **libre y gratuita** 

Abbie González la creó porque las fuentes similares eran caras e inaccesibles, así que la publicó bajo licencia open source para que todos puedan usarla.

**Descargas:**
- [Página oficial](https://opendyslexic.org/)
- [Extensión para Chrome](https://chromewebstore.google.com/detail/opendyslexic-for-chrome/cdnapgfjopgaggbmfgbiinmmbdcglnam?hl=es)

## Lexie Readable


![1000296501](web/adjuntos/7SL66L3F/1771296853754.avif)



Diseñada pensando en accesibilidad y legibilidad. Captura la claridad de Comic Sans pero sin el estilo de cómic. Tiene características que ayudan a lectores disléxicos: b y d asimétricas, formas manuscritas de a y g.

**Descarga:**
- [Página web](https://www.k-type.com/fonts/lexie-readable/)

Gratis para uso personal, educativo y benéfico.

## Easy Reading

![1000298455](web/adjuntos/7SL66L3F/1771296963481.png)

Tipografía **paga** (gratis solo uso personal) para idiomas con alfabeto latino. Creada por Federico Alfonsetti con enfoque en [Diseño Universal](https://en.wikipedia.org/wiki/Universal_Design).

Es la única fuente certificada científicamente como herramienta válida para personas con dislexia y facilitadora para todo tipo de lectores.

**Descarga:**
- [Página oficial](https://www.easyreading.it/en/)

Requiere llenar formulario. Gratis solo para uso personal.

## Cómo usarlas

### Navegador

1. Instala la Fuente deseada en tu Sistema.

2. Instalá la extensión Stylus desde Aqui
https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne


2. Agregá esta regla CSS específica;
3. Ajusta desde el Menu que Fuente y Emoji Quieres 

3. Todas las webs usarán tu fuente preferida 🤗

### Linux KDE

1. Instala la Fuente deseada en tu Sistema.
2. Andate a **Ajustes del Sistema** → **Fuentes** → **Instalar Fuente**
2. Seleccioná la fuente e instalala como "Fuente del Sistema"
3. Cerrá sesión y volvé a iniciar
4. Abrí Ajustes → **Temas y estilos** → ajustá la fuente con el tamaño que prefieras

Listo, todas las apps tendrán esa fuente 😍
