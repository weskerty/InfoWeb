# Accesibilidad en la web

Existen herramientas que facilitan el uso de Internet para personas con dificultades visuales o auditivas

## Dictador de Texto

Se llaman "TTS" y permiten convertir texto escrito en voz. Es útil para escuchar artículos, libros, mensajes y páginas web sin necesidad de leerlos. Ejemplo, esta web tiene el boton Escuchar alla arriba↗️ si presionas debe iniciar el dictado instalado en tu telefono, si no suena es que debes instalar alguno de estos:

- **Google TTS:** [Google Play](https://play.google.com/store/apps/details?id=com.google.android.tts)
- **RHVoice:** [F-Droid](https://f-droid.org/packages/com.github.olga_yakovleva.rhvoice.android/)
- **SherpaTTS:** [F-Droid](https://f-droid.org/packages/org.woheller69.ttsengine/)


### ¿Cómo configurar el TTS?

1. Instala el TTS de tu preferencia.
2. Busca «Texto a voz» en los ajustes
3. Selecciona la app y configura el tipo de voz .
4. Vuelve aqui a probar el boton escuchar ↗️

## Lectores de pantalla

Permiten escuchar el contenido de la pantalla y navegar sin necesidad de verla.

- **Android:** [TalkBack](https://play.google.com/store/apps/details?id=com.google.android.marvin.talkback).
- **Windows:** [NVDA](https://www.nvaccess.org/download/), gratuito y de código abierto.
- **Linux:** Orca, gratuito y de código abierto. (instalandose desde discovero linea de comandos)

## consejos de accesibilidad

- **Modo lectura:** Opcion del navegador que simplifica la web
- **Tamaño del texto:** esta pagina puede cambiarse de tamaño desde los 3 puntitos del navegador o presionando ctrl+rueda del raton o botones + y -
- **Modo oscuro:** Esta web tiene tema negro, pasa a revisar [➡️en ajustes](web/paginas/config.html)
- **Navegación con teclado:** Ajuste del navegador para manejarse con las teclas.
- **Reducir animaciones:** Ajuste en el sistema para desactivar animaciones.
